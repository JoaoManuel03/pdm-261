Avaliação 8, app de compras dinâmico, com 8 produtos, não possui banco de dadosn então as compras não ficam salvas.

OS PRINTS
O primeiro é sobre a tela inicial, direta, onde se coloca os produtos no carrinho.
O segundo é o proprio carrinho, onde se tem suas compras com o valor individual e também valor total.
A terceira é a mensagem que aparece quando se finaliza uma compra.
